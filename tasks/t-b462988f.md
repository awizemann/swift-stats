## Description

From the 2026-10-05 SDK audit, deferred: (1) iOS prewarm / launch before first unlock can read an empty UserDefaults suite → falls back to config defaults (an opted-out user collected from, new install UUID, seq 0); write a sentinel key once and fail closed if missing while SDK state exists on disk. (2) batchId and the 24h retention clock live only in memory; a background flush suspended then killed re-sends the batch under a new batchId (duplicate unless the backend dedupes on (project, install, seq)); persist the retained batch id/range/first-attempt time in a sidecar. Also: configured-consent downgrade (app update dropping a group without setConsent) is not treated as a revocation.
